# The Focus Window

A personal audiobook about channeling focus while your prescribed Adderall is active, built on the habit-formation science of *Atomic Habits* by James Clear.

**Total runtime:** ~28.5 minutes · MP3, 96 kbps mono · Voice: Piper TTS (en-US lessac, medium)

## Listen

- `audio/the-focus-window-full-audiobook.mp3` — the complete audiobook in one file
- `audio/00-*.mp3` … `audio/08-*.mp3` — individual chapters

## Chapters

| # | Chapter | Core idea |
|---|---------|-----------|
| 0 | Introduction | Medication opens the window; systems decide what climbs through it |
| 1 | Know Your Window | Log onset / peak / tail for 5 days (habits scorecard), then match tasks to phases |
| 2 | The Habit Loop, Amplified | Cue → craving → response → reward; stimulants run the craving stage hot, so the first cue steers the whole window |
| 3 | Design the Environment | Make the right task obvious and distractions invisible *before* the window opens |
| 4 | Launch Rituals | Habit stacking anchored to the daily dose + implementation intentions |
| 5 | The Two-Minute Doorway | The bottleneck is initiation, not sustaining — scale the start down to two minutes |
| 6 | The Tail & Never Miss Twice | Design the fade and comedown; no verdicts after the window closes; never miss twice |
| 7 | Identity & the Plateau | Each aimed window is a vote for a new identity; judge the system at six weeks, not six days |
| 8 | Outro: Your Day, Assembled | The whole system as one copyable sample day |

## Notes

- Full text of every chapter is in `script/` if you'd rather read, or want to edit and re-record.
- This assumes medication taken exactly as prescribed. Nothing here is medical advice — dose timing, amounts, and side effects are conversations for your prescriber.
- Concepts referenced from *Atomic Habits* (habits scorecard, four laws, habit stacking, implementation intentions, two-minute rule, temptation bundling, never miss twice, identity votes, plateau of latent potential) are paraphrased with attribution; the book itself is very much worth reading in full.

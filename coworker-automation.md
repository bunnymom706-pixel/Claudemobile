# One Place Locators — Cowork Automation

**Schedule:** Twice daily, 11:00 AM and 11:00 PM

## How to set it up

1. Open the Claude app (Cowork).
2. Create a new scheduled task / automation.
3. Set the schedule to run at **11:00 AM** and **11:00 PM** daily. If the app only allows one time per automation, create two automations with the same instructions — one for each time.
4. Paste the instructions below as the task prompt.

## Instructions to paste

```
You are my assistant for One Place Locators (apartment locating, Sophia Reddehase).
Do a business check-in and report back to me:

1. Check my Gmail for anything new since the last check-in:
   - New rental leads or client inquiries (anyone asking about apartments,
     tours, availability, or pricing).
   - Replies from properties or leasing offices I'm waiting on.
   - Anything time-sensitive (lease deadlines, tour confirmations, locator
     invoice/commission emails).

2. Give me a short summary, most important first:
   - Who reached out, what they want, and the suggested reply or next step.
   - Anyone I emailed who still hasn't replied after 2+ days (follow-up list).

3. Remind me of anything I said I'd do today that looks unfinished based on
   my emails.

Keep it brief and scannable — a few bullet points, no long paragraphs.
Do not send or reply to any emails yourself; drafts only if I ask.
```

## Notes

- The 11 PM run works as an end-of-day wrap-up; the 11 AM run catches the morning's leads.
- To change what it does, just edit the numbered list — plain English is all it needs.

# Leverage Check

The business is already chosen: apartment locating in Austin, licensed, referral commission. This skill does not question that. It asks a narrower question: is the work this week building something that pays again later, or is it pure labor that stops the moment Sophia stops?

One person cannot scale by working more hours. The only way income rises without a hire is leverage: something built once that keeps producing. This skill's job is to spot where that is missing and say so plainly.

## Before you start

Ask what changed since the last check, or what prompted this one. If nothing specific prompted it, that itself is worth naming, since this is a check-in, not a ritual to run on schedule for its own sake.

## The three buckets

Sort the actual work of the week into these. Do not invent categories.

**Labor.** Touring, phone calls, applications, negotiating with leasing offices, anything that requires Sophia in the room or on the line. This is the licensed, commissioned work itself. It is not a problem to fix, it is the product. Do not suggest systemizing away the core service.

**Systems.** Anything done once that removes repeated work later: the client tracking format, the income-letter-before-application step, a reusable intake template, the ad-copy format the `apartment-marketplace-ads` skill already runs. Ask what got repeated by hand this week that a template or checklist would absorb next time.

**Content or audience.** Anything that keeps working after it is published: a guide renters find on their own, a post that keeps generating replies days later, a relationship with a corporate relocation contact or another agent that sends referrals without being asked each time. This bucket is usually the thinnest one, because Facebook Marketplace posting is manual by design here and does not compound the way an audience does.

## Produce, in this order

**The audit.** A short table: task, which bucket it falls in, and one line on whether it already has leverage or is still pure repetition.

**The gap.** Name which bucket is thinnest. For most weeks here it will be content or audience, since manual Marketplace posting protects the account but does not build anything that outlasts the post.

**One move.** Not a roadmap. The single highest-leverage thing worth doing in the next week, sized to fit around client work rather than compete with it. It must have a plausible path to either saving hours on repeated labor or generating a lead without Sophia manually posting for it.

**The honest check.** Ask directly: is this audit itself the thing being used to avoid a harder conversation with a client or a lead? If yes, say so and stop, then hand off to `focus`.

## Rules

- Never suggest systemizing or automating the licensed, client-facing work itself. That is the business, not overhead.
- Never suggest automated Facebook Marketplace posting. The account is the pipeline and that risk stays closed.
- One move, not a list. A list of leverage ideas is a plan, and plans are not leverage.
- If the honest check turns up avoidance, name it once and route to `focus` instead of continuing the audit.
- Run this occasionally. If it is being asked for weekly, that is itself a sign it has become a way to feel productive instead of doing the labor that pays now.
